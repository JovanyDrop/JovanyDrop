Soy **Desarrollador Java Web Fullstack** con experiencia en el diseño, construcción y mantenimiento de soluciones empresariales a la medida. He participado en la evolución de sistemas legacy, desarrollo de nuevas funcionalidades e integración de módulos en distintas etapas del ciclo de vida del software.

Me enfoco en crear productos **claros, funcionales y mantenibles**, combinando desarrollo **frontend**, **backend** y **bases de datos** con una visión práctica orientada a resolver problemas reales.

- 💼 Experiencia en desarrollo web fullstack con enfoque empresarial

- 🚀 Interés en interfaces útiles, APIs sólidas y software mantenible
